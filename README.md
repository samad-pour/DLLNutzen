# DLLNutzen

Ein Visual-Studio-Projekt zur Einführung in die Einbindung und Verwendung von Dynamic Link Libraries (DLLs) innerhalb einer .NET-Anwendung.

## Beschreibung

Das Projekt **DLLNutzen** beschäftigt sich mit den Grundlagen der Verwendung externer DLL-Dateien in C#. Dynamic Link Libraries ermöglichen es, bereits entwickelte Klassen und Funktionen in unterschiedlichen Anwendungen wiederzuverwenden.

Im Mittelpunkt stehen die Einbindung einer DLL als Referenz, der Zugriff auf bereitgestellte Klassen und Methoden sowie die Verwendung externer Programmbibliotheken.

## Funktionen

- Einbindung externer DLL-Dateien
- Verwendung von Klassen und Methoden aus Bibliotheken
- Zugriff auf wiederverwendbare Programmkomponenten
- Verwendung von Namespaces und Referenzen
- Grundlagen der modularen Softwareentwicklung
- Trennung von Anwendungslogik und wiederverwendbaren Bibliotheken

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Dynamic Link Library (DLL)
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/DLLNutzen.git
   ```

2. Die Datei `DLLNutzen.sln` in Visual Studio öffnen.
3. Sicherstellen, dass alle benötigten DLL-Dateien vorhanden und korrekt referenziert sind.
4. Das Projekt erstellen.
5. Die Anwendung mit `F5` starten.
